# Sarah Itafa — Portfolio

React + Vite portfolio.

## Run locally

```bash
npm install
npm run dev
```

## Publish to GitHub Pages

```bash
npm install
npm run build
npm run deploy
```

On GitHub repository Settings → Pages, select **Deploy from a branch**, **gh-pages**, **/(root)**.

Live URL: https://sarahanwar-1.github.io/sarah-portfolio/

Pricing calculator is a separate site: https://sarahanwar-1.github.io/web-pricing-calculator/

Contact email and booking URL are in `src/App.jsx`.
